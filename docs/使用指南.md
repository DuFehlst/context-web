# context-web 使用指南

> 单包双视图插件：**会话地图**（组织跨会话/分支脉络）+ **Agent 画布**（观察单次运行的内部协作结构）。
> 本机状态：已安装（`link:` 到 `workbench\context-web`，改代码重启 dsh web 即生效）。

## 0. 两个入口

| 视图 | 入口 | 用途 |
|---|---|---|
| 会话地图 | 页面**顶部居中**的「对话 / 会话地图」胶囊切换 | 看全部会话与 fork 分支的脉络、就地追问/分支 |
| Agent 画布 | 任意会话的 **Tab 栏第三个**「Agent 画布」（在「对话」「轨迹」之后） | 看一次运行里 Agent/Subagent/Workflow/工具的关系图 |

---

## 1. 会话地图

### 1.1 界面布局
- **左侧栏**：品牌区 + 「新会话」按钮 + **工作区下拉**（按 DSH 工作目录分组，如 `dsh_0`、`agent-study`、`未分组`）+ 会话树（当前工作区的会话卡列表）。
- **右侧画布**：会话卡片与连线；顶栏「地图 / 详情」切换 + 缩放、重置视图按钮。

### 1.2 卡片与连线（血缘）
- 一张卡 = 一个 DSH 会话；一条线 = **fork 分支关系**（父会话 → 子会话），分支点锚在 fork 发生的那条消息上，不是随便画的。
- 卡片标题 = 会话首问或 DSH 会话标题；卡内展示该会话的问答摘要。
- 颜色按主题轮换（5 色），同一分支继承父卡颜色。
- **工具调用折叠在所属回答卡里**（按 callId 配对调用/结果，不会单独占一张卡）。
- 运行中的会话卡片有状态点脉冲动画；错误轮次显示错误卡（红色）。

### 1.3 画布操作
- 拖背景 = 平移；滚轮 = 缩放（0.2×～4×）；拖卡片 = 调位置（**持久化**到数据文件与 localStorage）。
- 卡片下方连接器上的 **＋ = 追问**；**分支图标 = 在新对话中分支**；**折叠图标 = 收起子分支**。
- 点卡片 → **详情视图**：完整消息流（用户/助手/todo/错误，带角色头像）+ 工具调用过程列表 + 「继续追问」入口。
  - 注意：详情里的消息是**投影**（单条 ≤8000 字符，超长截断并提示「详情查看全文」）；完整历史在 DSH 原生会话。

### 1.4 追问与分支（双向同步核心）
- **选中回答中的文字** → 出现「追问」浮钮 → 打开草稿框：选中文字作为引用，可点常用短语（展开说明 / 举例 / 通俗易懂 / 对比解释，可编辑增删）→ 发送后由 **DSH 真实会话执行**（消息进入原会话队列，不是画布自嗨）。
- **分支**：走 **DSH 原生 fork**（从锚点复制历史起新会话）→ 地图出现子卡并连线。
- 双向同步：
  - 地图里点会话树行/卡片 → DSH 打开对应会话（**地图不关闭**）；
  - 地图里切会话 → DSH 当前会话跟随；
  - DSH 里 fork / 切会话 → 地图自动跟进高亮与新节点。

### 1.5 归档与重置
- 删除卡片（详情里操作）→ 从画布移除该会话节点（含子分支），**DSH 会话本身不动**；后续同步不会复活（有 hiddenSessionIds 防复活）。
- 重置画布：删除 `$DSH_HOME\context-web\workspaces.json`（默认 `C:\Users\Administrator\.dsh\context-web\workspaces.json`）→ 画布归零、**不删任何 DSH 会话**，重启后自动重建。

### 1.6 主题
跟随 DSH 明暗模式自动切换，无需配置。

## 2. Agent 画布

### 2.1 图模型
```
主 Agent（圆节点）
├── Workflow（卡片）→ Phase（卡片）→ Subagent（卡片）   # workflow 成员不重复连回主节点
├── 直接 Subagent（卡片，不属于任何 workflow 的子代理）
└── 工具节点（圆）：运行中的工具调用（虚线）+ 最近 12 个工具结果（防图过密）
```

### 2.2 状态与颜色
| 状态 | 表现 |
|---|---|
| 运行中 | 绿色（workflow 蓝），脉冲光圈动画 |
| 失败 | 红色 |
| 取消 / 中断 | 橙色 |
| 完成 / 空闲 | 灰色 |

### 2.3 交互
- 拖节点 / 拖背景 / 滚轮缩放；右侧按钮 **＋ / − / ⟳**（放大 / 缩小 / 重置视图）。
- **⚙ 力导向设置**：向心力、节点排斥力、连线吸引力、连线自然距离、阻尼 5 个滑块实时调节 + 「恢复默认」；参数持久化到 localStorage（`context-web:sim-params`）。
- **只读观察**：节点不可点击操作任务；数据与「对话」「轨迹」同源，实时更新。

### 2.4 前提
模型需启用 subagent/workflow 工具（由 agent preset 控制）。若图上只有主 Agent，在 profile 的 cordis.patch.yml 启用相关行（示例见仓库 README「使用 Subagent / Workflow 的配置提示」）。

## 3. 配置（可选，profile 的 cordis.patch.yml 覆盖）

```yaml
- id: context-web
  config:
    dataFile: !!js dshHomePath('context-web/workspaces.json')  # 画布元数据位置
    autoProjection: true            # 自动投影已提交的会话事件
    projectionWorkspaceTitle: DSH 任务   # 未分组工作区标题
    trustedHosts: []                # 局域网/远程访问时加 host 或 host:port
```

改配置后重启 dsh web 生效。

## 4. 常见问题

| 现象 | 处理 |
|---|---|
| 看不到「会话地图」按钮 / 「Agent 画布」Tab | 插件安装/更新后**必须重启 dsh web**（插件集变化不热加载），再浏览器强刷（Ctrl+F5） |
| 地图空白 / API 报错 | 看 dsh web 启动日志有无 FAILED；访问 `http://127.0.0.1:3080/context-web/` 应 200 |
| 启动日志提示「另一个 dsh web 实例正在写入」 | 有第二个实例在跑；多实例 last-writer-wins，关掉多余实例 |
| 远程/局域网访问地图 403 | 在 patch 里给 `trustedHosts` 加访问域名或 IP:端口 |
| 画布乱了想重置 | 删 `$DSH_HOME\context-web\workspaces.json` 后重启（DSH 会话不受影响） |
| 卸载 | `dsh plugin --profile web remove context-web`；数据文件保留，重装后画布还在 |

---

## 5. 已知限制（继承自上游设计）

- 详情只展示投影内容（≤8000 字符截断），完整历史以 DSH 原生会话为准。
- 仅支持 web profile；建议只跑一个 dsh web 实例。
- 内部线协议沿用上游 `synapse:` 前缀（不影响使用）。
